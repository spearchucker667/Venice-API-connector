# Venice Forge Localization Glossary

This glossary defines product-specific terminology and translation guidelines across all supported languages.

| English Term | Description / Guidance |
|---|---|
| **Venice Forge** | Product name. Do not translate. |
| **Profile** | User environment containing renderer settings and asset libraries. |
| **Workspace** | Project or document context boundary. |
| **Prompt** | User instruction or AI system instruction. |
| **Character Card** | V2 PNG or JSON character specification for RP. |
| **Family Safe Mode** | Local master-password-protected content filter. |
| **Provider** | Remote AI service endpoint (Venice, Jina). |
| **Model** | Specific AI model identifier. Do not translate IDs. |
| **Seed** | Random seed number for media generation. |
| **Negative Prompt** | Descriptors to avoid in image/video generation. |
| **Embedding** | Vector memory representation. |
| **Lorebook** | World-info key-triggered memory catalog. |

# Venice Forge — 한국어

> [영어 문서 (표준)](../../../README.md)

Venice Forge는 Venice.ai API를 위한 로컬 프라이빗 데스크톱 클라이언트입니다.

## 주요 기능

- **프라이빗 다중 모델 채팅**: 언어 및 비전 모델을 지원하는 고도의 프라이버시 채팅 인터페이스.
- **캐릭터 빌더 및 RP 스튜디오**: V2 PNG 및 JSON 캐릭터 카드를 디자인하고 가져오는 도구.
- **미디어 스튜디오 및 이미지 생성**: 이미지, 비디오, 오디오 생성.
- **네이티브 프라이버시 및 보안**: API 키와 시크릿은 OS의 보안 스토리지에 암호화됩니다.
- **다국어**: 10개 인터페이스 언어 완벽 지원.

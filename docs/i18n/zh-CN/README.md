# Venice Forge — 简体中文

> [英文文档（规范）](../../../README.md)

Venice Forge 是一个用于 Venice.ai API 的本地私有桌面客户端。

## 主要功能

- **隐私多模型聊天**：支持语言和视觉模型的高隐私聊天界面。
- **角色构建器和 RP Studio**：用于设计和导入 V2 PNG 和 JSON 角色卡的工具。
- **媒体工作室和图像生成**：创建图像、视频和音频。
- **原生隐私与安全**：API 密钥和机密被加密存储在操作系统的安全存储中。
- **多语言**：全面支持 10 种界面语言。
